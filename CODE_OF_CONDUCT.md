# Code de conduite

Ce dépôt suit le [code de conduite de Major League Hacking](https://static.mlh.io/docs/mlh-code-of-conduct.pdf).

On participe pour que quelqu'un à Lomé comprenne une photo avant de donner de l'argent ou une marchandise. Le désaccord sur un écran ou un modèle se règle dans la pull request, sans attaque personnelle.

Un comportement qui contredit ce code se signale aux organisateurs de l'événement, via le canal indiqué par MLH et Python Togo.
